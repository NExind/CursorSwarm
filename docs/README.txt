CursorSwarm v10.9
Created by Palugula Tharun Kumar

CursorSwarm is a Windows desktop visual effects app that creates cursor swarm overlays, mirror movement effects, and customizable cursor presets.

LATEST VERSION
CursorSwarm v10.9

WHAT'S NEW IN v10.9
- Control Panel opens automatically on launch.
- Floating CS button appears when the Control Panel is hidden.
- Clicking the CS button opens the Control Panel.
- Right-clicking the CS button shows Open Control Panel and Hide Floating Button options.
- Ctrl + Alt + C still toggles the Control Panel.
- Only the main CursorSwarm shortcut is exposed in the Start Menu.
- Certification notes and full-trust desktop explanation were updated.

IMPORTANT NOTES
CursorSwarm is a local Windows desktop app.

It does not collect personal data, upload files, record user activity, or send data to a server.

The app uses local Windows desktop functionality for cursor overlay effects, mirror movement mode, global keyboard shortcuts, local mouse movement handling, and cursor visibility control.

SAFETY
CursorSwarm includes restore and safety controls so users can return the cursor to normal if cursor effects are enabled.

If the Control Panel is hidden, the floating CS button can be used to open it again. Ctrl + Alt + C can also be used to toggle the Control Panel.
