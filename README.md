# CursorSwarm

CursorSwarm is a local Windows desktop app for cursor visual effects, cursor customization, fake cursor swarms, movement effects, click effects, presets, themes, performance controls, and safe cursor restore tools.

## Latest Stable Version

**CursorSwarm v13.12**

CursorSwarm v13.12 is the stable release checkpoint prepared for Microsoft Store distribution. It includes the modern CustomTkinter control panel, Cursor Lab, movement effects, click effects, full themes, custom multi-colour presets, startup behavior options, performance controls, and safety/restore improvements.

## Main Features

- Cursor Lab customization
- Fake cursor swarm visual effects
- Manual cursor shape library
- Animated Busy / Loading and Working in Background cursor support
- Cursor tint, bright neon tint, multi-colour tint, and black outline options
- Idle effects such as pulse, glow ring, fade, and wobble
- Movement effects including motion trail, speed glow, motion streak, spark particles, ripple burst, comet tail, speed lines, and magnetic orbit
- Click effects with ripple, burst ring, sparks, and combined styles
- Full cursor themes with save/load/export/import support
- Custom multi-colour preset manager
- Startup behavior options
- Performance controls for target FPS and battery saver settings
- Run Stability Check
- Safe Quit and emergency cursor restore support

## Safety and Privacy

CursorSwarm runs locally on the user's Windows device.

CursorSwarm does **not** collect, sell, share, or transmit personal data. It does not require account sign-in and does not run background network services. Settings, presets, themes, and restore-related files are stored locally on the device.

The app uses Windows desktop functionality for cursor overlays, local mouse-position based effects, global hotkeys, and safe cursor restore behavior.

## Build

Install dependencies first:

```powershell
python -m pip install pyinstaller customtkinter pillow keyboard pywin32
```

Build the app:

```powershell
python -m PyInstaller --onefile --noconsole --name CursorSwarm --icon=cursor_swarm.ico --version-file=packaging\cursor_swarm_version_info_v13_12.txt --collect-data customtkinter src\cursor_swarm_v13_12.py
```

The output executable will be created in:

```text
dist/CursorSwarm.exe
```

## Microsoft Store / MSIX Notes

CursorSwarm is a packaged Win32/Python desktop app and uses the `runFullTrust` capability for local desktop cursor functionality. The app does not collect or transmit personal data.
