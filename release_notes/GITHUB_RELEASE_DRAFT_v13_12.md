# CursorSwarm v13.12

CursorSwarm v13.12 is the stable release checkpoint prepared for Microsoft Store distribution.

## Highlights

- Modern CustomTkinter control panel
- Cursor Lab customization
- Manual and animated cursor shape support
- Idle effects, movement effects, and click effects
- Full cursor themes and startup behavior options
- Custom multi-colour preset manager
- Performance controls and battery-saver options
- Stability check improvements
- Safe Quit and emergency cursor restore support
- Refreshed README, release notes, privacy policy, terms/safety text, build notes, and certification notes

## Notes

This release is intended as the stable public Store/GitHub checkpoint. Experimental v14.x auto-switch and shape-profile work is not included in this stable release branch.
